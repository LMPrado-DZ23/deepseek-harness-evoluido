# P37 — artemis

Inventário de referência externa produzido ANTES de qualquer uso, como o produto
exige. Como no P37 do WebMCP, aqui **nada é copiado**: o que se avalia é USAR uma
ferramenta externa de QA, fora do artefato, no computador de quem testa.

- projeto: ARTEMIS — ferramenta que deixa assistentes de IA e suítes de teste operarem APARELHOS ANDROID REAIS por linguagem natural, com localização multimodal de elementos (sem XPath/ID frágil), captura de Logcat e de quadros-chave, e servidor MCP nativo para IDEs. Publicado pela organização `google` no GitHub.

- dependencias_e_lockfiles: Python 3.12+, e o próprio projeto instala cadeia de ferramentas do sistema — ADB, scrcpy, FFmpeg e dependências Python via `uv`. NENHUMA delas entra no lockfile do DZ23, porque a ferramenta não é dependência do produto. O cliente Python (`artemis-client`) seria instalado na máquina de teste, não aqui.
- rede_filesystem_segredos: este é o campo que decide, e a resposta tem duas metades. (1) A ferramenta pede uma chave de modelo MULTIMODAL (Gemini, Claude, GPT-4o ou Qwen-VL) e ENVIA CAPTURAS DE TELA DO APARELHO para o modelo — ou seja, tudo que estiver visível na tela durante o teste sai do aparelho. (2) Ela recebe controle de ADB sobre um aparelho real e captura Logcat. Consequência decidida aqui: a prova de D-09 roda em APARELHO DEDICADO DE TESTE ou emulador, com conta de teste, NUNCA no telefone pessoal do Prado — um agente com ADB e captura de tela num aparelho com contas reais está com as sessões dele na mão, e nenhum benefício de prova justifica isso.
- cves_conhecidas: nenhuma CVE localizada para o projeto. Ausência de resultado em busca não é prova de ausência de vulnerabilidade. A superfície relevante aqui não é a do produto DZ23 (a ferramenta não entra nele): é a da máquina de teste e a do aparelho de teste, e é por isso que o campo acima confina os dois.
- sbom: não se aplica ao artefato do DZ23 — nenhum componente novo entra nele. O SBOM do produto continua o mesmo depois desta decisão.
- sast: não executado, e não se aplica ao caminho de execução do produto: nenhuma linha de ARTEMIS roda dentro do DZ23. O que roda dentro do DZ23 continua passando pelos portões deste repositório.
- poc_isolado: NAO_VERIFICADO — motivo objetivo e verificável: ARTEMIS exige ADB e um aparelho Android físico (ou emulador) ligados ao host, e este ambiente de nuvem não tem nenhum dos dois. Também exige chave de modelo multimodal, que é o mesmo bloqueio do P-07. O PoC é a própria execução do D-09, e ele acontece na máquina do Prado.
- veredito: SIM para uso como ferramenta externa de QA na prova do D-09 (PWA em aparelho físico), e NÃO para qualquer entrada no produto — não é dependência, não vai para a imagem, não vai para o SBOM. Nada é copiado. As condições do veredito: aparelho DEDICADO de teste com conta de teste, e consciência de que capturas de tela do aparelho saem para um modelo externo durante a execução.
