# Livro mestre de requisitos — DZ23 STUDIO

Uma linha por requisito do `PROMPT_MESTRE_TOTAL_CLAUDE_DZ23_STUDIO_20260907.md` e do
Plano Mestre. **Nenhuma linha usa `PASS`, "pronto" ou "funciona".** Os estados são
os da ADR-005 mais os deste prompt:

`STABLE` · `BETA` · `EXPERIMENTAL` · `DISABLED` · `UNSUPPORTED` ·
`NOT_PRESENT` · `NOT_CONFIGURED` · `NOT_EXECUTED` · `BLOCKED_EXTERNAL` · `FAILED`

`FAILED` significa que a prova foi executada e reprovou, **ou** que o
comportamento contradiz o requisito escrito.

**Reconciliação desta versão:** branch `claude/integration-candidate-20260907`,
HEAD `66e889e`. O prompt mestre cita `4bdb253`; a candidata avançou seis commits
desde então (`b2fd910`, `5822c02`, `517e70c`, `66e889e` e os dois anteriores),
todos com auditoria independente registrada em
`audit/THREE_AGENT_REVIEW_20260908.md`.

O levantamento que originou os estados abaixo foi feito por quatro agentes
independentes lendo código e testes — não README, não nome de arquivo, não
intenção. Onde um teste só cobria mock ou fixture, o estado registrado é
`NOT_EXECUTED`, não `BETA`.

Requisitos destinados a v1.x/v2 **não são apagados**: ficam aqui com a versão-alvo
declarada.

## Como ler a coluna "prova real"

- **execução** — foi rodado nesta árvore e a saída está citada.
- **teste** — existe teste automatizado que exercita o comportamento real.
- **fixture** — existe teste, mas sobre dado simulado; não prova funcionamento.
- **nenhuma** — não há prova.
