# Cartão da pessoa participante

O facilitador lê somente a frase abaixo e entrega o computador. Não explique
botões, etapas ou termos.

> Imagine um aplicativo simples que ajudaria você no dia a dia. Peça ao sistema
> para criar esse protótipo.

Se a pessoa perguntar “o que eu faço?”, responda apenas:

> Faça como faria se estivesse pedindo ajuda a uma pessoa.

Qualquer orientação adicional deve ser registrada como ajuda no formulário.
