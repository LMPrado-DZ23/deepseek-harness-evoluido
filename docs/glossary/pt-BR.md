# Glossário pt-BR do DZ23 STUDIO

| Termo da interface | Significado em linguagem comum |
| --- | --- |
| Ideia | O que a pessoa quer criar, descrito com as próprias palavras. |
| Perguntas | Confirmações curtas feitas uma por vez para reduzir suposições. |
| Plano | Lista visível do que será criado e de como será conferido. |
| Criação | Geração e testes dentro do ambiente isolado, sem publicação. |
| Verificação | Evidências de compilação, testes, acessibilidade e segurança. |
| Protótipo verificado | Artefato local que passou nas verificações declaradas; não é aplicação publicada. |
| Privacidade local | Somente uma IA local pode receber a ideia e as respostas. |
| IA configurada | A rota exibida pode receber a ideia e as respostas; os arquivos permanecem locais. |

Os identificadores técnicos permanecem ao lado do texto comum nos relatórios,
para auditoria. Eles não substituem a explicação destinada à pessoa leiga.
