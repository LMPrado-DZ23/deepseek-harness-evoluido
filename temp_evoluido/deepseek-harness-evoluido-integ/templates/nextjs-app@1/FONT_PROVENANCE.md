# Fontes locais do template

- Geist 1.7.2: pacote `geist`, projeto Vercel Geist, licença SIL Open Font
  License 1.1. O template usa somente
  `dist/fonts/geist-sans/Geist-Variable.woff2` via `next/font/local`.
- Source Serif 4 variável 5.3.0: pacote
  `@fontsource-variable/source-serif-4`, fonte Adobe Source Serif 4, licença SIL
  Open Font License 1.1. O template usa somente
  `files/source-serif-4-latin-wght-normal.woff2` via `next/font/local`.

Versões e integridade ficam fixadas em `package.json` e `pnpm-lock.yaml`. Nenhuma
fonte é baixada durante build, execução ou navegação.
